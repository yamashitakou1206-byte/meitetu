# 名鉄運行表示 Web版

スクリーンショットをベースにした、ブラウザで動く試作版です。

## 起動
`index.html` をChrome / Edge / Safariで開いてください。
インターネット接続なしでも、画面・時計・サンプル時刻表は動作します。

## 現在の機能
- スクリーンショットに近い2カラム運行表示
- 列車種別、行先、列車番号、停車駅・時刻表示
- デジタル時計＋アナログ時計
- 1秒ごとの時計更新
- 5秒ごとの表示更新
- 拡大・縮小
- 明暗表示切替
- 名鉄公式運行情報を開くボタン

## 実運用へ拡張する場合
この版は「画面を先に完成させる」ため、時刻表データはサンプルです。
実際の名鉄の最新時刻・運行情報を自動取得する場合は、公式サイトの利用条件や取得方法を確認した上で、サーバー側APIを用意してデータを取得する構成にするのがおすすめです。

公式:
https://top.meitetsu.co.jp/em/
https://www.meitetsu.co.jp/train/timetable/
